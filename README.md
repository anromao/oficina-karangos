# 🏁 Karangos Motor Sport — Website Oficial

> Site institucional moderno e de alta performance desenvolvido para a **Karangos Motor Sport**, oficina de referência em preparação automotiva de competição, motores turbo e aspirados, acerto eletrônico e injeções programáveis em São Paulo.

---

## 🏎️ Sobre a Karangos Motor Sport

A **Karangos Motor Sport** é especializada em preparação automotiva de alto rendimento, unindo precisão mecânica, eletrônica avançada e paixão pelo automobilismo esportivo:

* ⚡ **Preparação Turbo & Aspirado:** Montagem, forjamento e calibração de motores de alta performance.
* 🔌 **Injeção Programável Credenciada:** Oficina autorizada e especializada em **Octtane ECU** e acertos avançados.
* 🏆 **Projetos de Competição:** Carros preparados para arrancada, manobras, drift e exibição.
* 🚗 **Restauração e Clássicos:** Especialistas em veículos antigos e colecionáveis, preservando estilo e potência de época.
* 🔧 **Manutenção Preventiva & Frotas:** Serviços mecânicos com padrão de qualidade de competição para veículos de rua e frotas.

## 🛠️ Stack Tecnológica

O projeto foi construído seguindo os padrões modernos da Web (W3C), priorizando performance máxima, SEO e responsividade:

| Camada | Tecnologia | Descrição |
| :--- | :--- | :--- |
| **Estrutura** | `HTML5 Semântico` | Marcação semântica com metadados Open Graph e Schema.org para SEO |
| **Estilização** | `CSS3 Moderno` | Design responsivo, Glassmorphism, CSS Grid, Flexbox e animações fluidas |
| **Interatividade** | `Vanilla JavaScript` | Comportamentos dinâmicos, modais, carrosséis, status de horário em tempo real |
| **Ícones & Tipografia** | `FontAwesome 6` / `Google Fonts` | Ícones esportivos e tipografia moderna |

## 🚀 Como Executar o Projeto Localmente

Por ser um projeto web estático, não há necessidade de instalação de dependências ou servidores backend.

### Opção 1: Direto no Navegador
1. Faça o clone do repositório:
   ```bash
   git clone https://github.com/anromao/oficina-karangos.git
   ```
2. Acesse a pasta:
   ```bash
   cd oficina-karangos
   ```
3. Dê um duplo clique no arquivo `index.html` ou abra-o em seu navegador favorito.

### Opção 2: Com Live Server (VS Code / Extensões)
* Abra o diretório no VS Code e clique em **"Go Live"** com a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).

## 🌐 Publicação (GitHub Pages)

Para hospedar o site gratuitamente no **GitHub Pages**:

1. Acesse o repositório no GitHub: `https://github.com/anromao/oficina-karangos`
2. Vá em **Settings** > **Pages**
3. Em **Source**, selecione a branch `main` e a pasta `/ (root)`
4. Clique em **Save**. Em instantes seu site estará online em:
   `https://anromao.github.io/oficina-karangos/`
